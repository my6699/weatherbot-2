二、盈亏平衡公式推导

Taker 盈亏平衡

// Taker 策略：主动吃单，必成交，但付滑点
EV = 胜率 × 赢时利润 - 输率 × 输时亏损

// 双桶区间：成本 C1 + C2，任意一桶赢就获 $1
EV = P(赢) × ($1 - C1 - C2) - P(输) × (C1 + C2)
EV = P(赢) - (C1 + C2)

// 盈亏平衡条件：P(赢) = C1 + C2
门槛 edge = 模型概率 - 市场价 - 滑点 > 0
// 实际门槛：edge > 3%（代码中 scoring 设的阈值）

Maker 盈亏平衡

// Maker 策略：挂限价单，不一定成交，但无滑点成本
// 分两个阶段计算：

// 阶段一：单笔成交后的 EV（挂单后成交了）
EV_成交 = 胜率 × ($1 - 入场价) - 输率 × 入场价
EV_成交 = 胜率 - 入场价

// 盈亏平衡：胜率 > 入场价
门槛：模型概率 > 挂单价

// 阶段二：考虑成交率的真实 EV
EV_真实 = 成交率 × EV_成交 - (1 - 成交率) × 0
// 未成交的订单不亏钱（只是锁定资金）
资金效率 = 成交率 × 单笔 ROI × 资金周转次数

关键差异：两个平衡点不一样

// Taker 平衡的是"胜率 vs 成本"
Taker: 需要 P(赢) > 入场价 + 滑点

// Maker 平衡的是"胜率 vs 挂单价"
Maker: 需要 P(赢) > 挂单价

// 看似 Maker 门槛更低（没滑点），但实际约束更强：
Maker 的入场价（5-15¢）远低于 Taker（30¢/桶）
// 这意味着：
// Taker 需要 65% 胜率才能覆盖 60¢ 成本
// Maker 只需要 6.88% 胜率就能覆盖 5¢ 成本
// 但低胜率意味着结果高度离散，需要大样本才能稳定

四、隐藏的"冰山"—— 两种策略真正的风险点

Taker 的隐藏风险

滑点成本~2-5% 每笔，累计吃掉利润
流动性不足D3/D2 市场薄，大单会拉高成本
首日价格混乱刚开市时价格波动大，容易买贵
资金利用率高（但 bankroll 小，限制规模）
最大回撤单笔亏损可达 65%（双桶全输）

Maker 的隐藏风险

逆向选择你被成交的订单往往是"别人不想持有的"
被扫单预报更新后没及时撤单，被人捡尸
资金锁定70-90% 的挂单不成交，资金空转
响应速度需要毫秒级撤单，VPS 可能不够
竞争压力和 jjavi 等专业做市商抢单

五、混合策略具体方案

方案一：主 Taker + 辅 Maker（推荐）

维度 Taker 部分（主力 80%） Maker 部分（补充 20%）
进场时间 D3/D2 提前进场 D0 当天补充
选桶逻辑 双桶区间，模型概率 > 市场价 + 3% 单桶，只看 < 20¢ 的极端便宜桶
资金分配 80% bankroll（~$80） 20% bankroll（~$20）
订单类型 Taker：市价/吃单 Maker：限价单，挂在最佳 Bid 之上 1-2¢
监控要求 每小时轮询（现有架构） 需要秒级监控（新模块）
退出策略 持有到结算 持有到结算
预期收益 稳定正期望，每笔 +5-15% 高波动，但利润因子高（6.45）

方案二：全 Maker + 提前挂单（激进）

放弃 Taker，全面转 Maker。D3 就开始挂限价单，挂到 D0 等成交。

风险D3/D2 没有流动性，挂单 3 天不成交，资金全锁死

风险我们资金量小（$100），挂单分散后单笔占用更少
机会如果架构能跟上，可以吃到全部 Maker 红利

七、决策边界 —— 什么情况下该选哪种策略？

✅ 选 Taker

当市场刚开（D3/D2），流动性一般，但模型概率明显高于市场价（edge > 8%）

✅ 选 Maker

当接近 D0，预报高度确定，能找到 < 20¢ 的极端便宜桶，且城市流动性好

⚠️ 都不做

当 edge 不够（< 3%），或流动性太差（深度 < $100），或离散度太高

❌ 别做 Maker

当市场流动性差（非头部城市），或预报还有大不确定性（D3/D2），或资金太少分散不开

结论：推荐方案一（主 Taker + 辅 Maker）

  • 不改动现有核心逻辑——Taker 部分保持现有代码运行，回测已验证正期望
  • 新增 Maker 模块作为补充——只在高流动性城市（London/NYC/Seoul）的 D0 当天挂单，吃 < 20¢ 的便宜桶
  • Maker 资金占比不超过 20%——$20 的 Maker 资金，分散到 10-15 个挂单，被扫单了也不伤筋动骨
  • 先跑通 Maker 逻辑再放量——先 paper 模式跑 Maker 挂单，验证成交率和胜率，再逐步加资金
  • Maker 的预期增量收益不大（月 +$0.60），但能分散风险、平滑收益曲线
